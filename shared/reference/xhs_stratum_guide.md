# 小红书圈层 Lens — Persona 自动生成的理解框架

> 这份文档是 `vd persona-init` 的"理解透镜"。读取一个账号的 raw data（bio + 笔记列表 + detail）后，按这套框架解读，再合成 persona JSON。
>
> 目标：**站在小红书博主圈层视角**理解一个账号，而不是简单的 NLP/词频。

---

## 一、bio 解读模式（第一时间判赛道）

### 1.1 常见 bio 语法结构

| 模式 | 示例 | 含义 |
|---|---|---|
| `[职业/身份] \| [赛道] \| [定位]` | "心理咨询师 \| 关系修复 \| 慢慢来" | 标准三段式 |
| `[动作] \| [价值主张]` | "拆解思维陷阱 \| 用逻辑重建认知" | 知识型/工具型 |
| `[圈层标签 emoji] [身份] [IP]` | "📍上海｜🎯30+创业｜🍑职场情绪" | 标签流（女性向） |
| `[反主流自述]` | "在小红书做一个不合时宜的深度探索者" | 反共识型/小众型 |
| `[名人引用 / 节目 IP]` | "全球 Top 0.1% 播客" | 权威背书型 |

### 1.2 bio 中的关键信号

**抓的字段**：
- **职业/身份动词**（拆解 / 教 / 分享 / 记录）→ 决定 voice 是教师/同行/记录者
- **价值主张**（用逻辑重建认知 / 让你少走弯路）→ 决定 promise
- **赛道关键词**（思维 / 关系 / 情绪 / 职场 / 减脂）→ 决定主题 cluster
- **数字 / 资历**（10 年 / Top 0.1% / 985）→ 决定信任锚类型
- **反主流措辞**（不合时宜 / 深度 / 慢慢来）→ 决定与主流圈层的张力位置

## 二、心理/成长大圈层下的 6 个子圈层

每个子圈层的 voice、形式、用户都不同。Persona 生成时必须先判定子圈层。

| 子圈层 | 标志 voice | 标志形式 | 典型用户 | 对应已知账号 |
|---|---|---|---|---|
| **认知派 / 反共识** | 「永远不是 X」「真相是 Y」「打破 X 神话」 | 文字图文卡片 | 25-35 城市职场，反思型 | 真相拆解师 / 谢胜子 / 爽子 |
| **治愈共情派** | 「先接住自己」「允许」「可以的」 | 金句文字图 + 暖色 | 25-30 高敏感女性 | 治愈果 / 月亮日记 |
| **干货实操派** | 「N 个步骤」「亲测有效」「保姆级」 | 数字清单 + 视频干货 | 25-40 职场/学生 | 能量素 Chrissie / 现在是昊宽 |
| **心理学权威派** | 「依恋理论」「自体心理学」「来访者反映」 | 图文长文 + 概念词 | 25-35 心理学爱好者 | INSEEL / Eya 疗愈宇宙 |
| **女性成长派** | 「30+」「创业」「主体性」「向内求」 | 图文 + 偶尔 vlog | 28-40 女性创业者/自由职业 | 萧萧 Carol / 来都来了播客 |
| **生活感叙事派** | 「有时候我会」「最近发现」「就这样」 | vlog + 生活图文 | 25-35 文艺女性 | 丸籽本丸 |

### 2.1 子圈层判定规则

按权重投票：bio voice 词 × 4 + 标题词频 × 3 + 形式分布 × 2 + 笔记主题分布 × 1。

例：
- bio 含「拆解」「逻辑」「真相」 → 认知派 +12
- 标题 30 篇里 15 篇是「永远不是 X」 → 认知派 +45
- 100% 图文 → 认知派 / 治愈派 / 心理学派 都+，干货派/生活感派 -
- 主题集中在「关系/认知/反思」 → 认知派 +1

## 三、voice signature phrases 提取规则

### 3.1 从标题里挖

按"标志短语 + 出现频率"提取：

```
扫描所有 30 条标题 → 找出现 ≥3 次的固定短语 → 输出 voice_signature_phrases
```

### 3.2 圈层默认词库（fallback）

如果标题里挖不到强信号，按子圈层用默认词库填充：

- **认知派**：「真相是」「拆解一下」「其实你」「看清这一点」
- **治愈派**：「慢慢来」「先接住自己」「允许」「可以的」
- **干货派**：「亲测」「保姆级」「步骤」「直接抄」
- **心理学派**：「依恋理论说」「来访者教我」「我们在做的」
- **女性成长派**：「30+」「向内求」「主体性」「她力量」
- **生活感叙事**：「最近」「有时候」「就这样」「散步的时候」

## 四、form_capability 推断

从 `note_type` 分布 + 已有 cover 比例推断：

| 观察 | form_capability 推断 |
|---|---|
| 100% normal + 1200x1600 比例 | 图文卡片为主 = `图文卡片: true, 图文长文: true, 视频: false` |
| 100% normal + 长 desc + 大量段落 | 图文长文 = `图文长文: true, 图文卡片: maybe` |
| 100% video | 视频/口播 = `口播: true, vlog: maybe, 图文: false` |
| 70/30 normal/video 混合 | 全形式 = `图文: true, 口播: true, vlog: true` |
| 0 笔记 | 默认全形式开放，等用户跑过再 enrich |

---

## 五、constraint 推断（红线）

从 bio 调性 + 笔记选题 + 是否带购物链接推断：

| 信号 | 推断的 constraint |
|---|---|
| bio 含「不合时宜」「深度」「探索」 | "不要追热点 / 不要快餐内容" |
| bio 不含商业身份 / 0 带购物链接 | "不卖课、不立大师人设" |
| 选题没有"教你/救你"等俯视语气 | "不用「教你 / 救你」这种俯视语气" |
| 100% 反共识公式 | "不要写常规鸡汤 / 干货清单" |
| 笔记主题集中「关系」 | "不要讨好型人格、不要讨好读者" |

---

## 六、可挪用 story_assets 提取

如果 bio 或笔记 desc 里有明确身份故事（创业 N 年 / 做了什么产品 / 经历过 X），抓出来作为 story_assets。

如果没有（**像真相拆解师这样匿名化的账号**）：留 `story_assets: []`，加注释说明 "需要用户后续手动补充"。

## 七、persona_anchors_for_rewrite 推导

| 子圈层 | professional_id | career_stage | audience_match | differentiator |
|---|---|---|---|---|
| 认知派 | 反套路心理观察家 / 认知拆解者 | 持续输出中 | 25-35 反思型职场用户 | 不安抚 / 解构 / 让你看清 |
| 治愈派 | 心理疗愈者 | — | 25-30 高敏感女性 | 让你松弛 / 被接住 |
| 干货派 | 心理学方法论传播者 | — | 25-40 找方法的人 | 给具体步骤 / 立刻可用 |
| 女性成长派 | 30+ 女性创业者 IP | 创业 N 年 | 28-40 同行/同温层 | 我走过你正在走的路 |

## 九、合成 persona JSON 的输出 schema

```json
{
  "_meta": {
    "version": "0.1-auto",
    "synthesized_at": "<ISO date>",
    "source": "xhs auto-extracted from <user_id>",
    "lens_version": "xhs_stratum_guide v1",
    "needs_user_review": true
  },
  "core_tags": [],          // 1-3 条，从 bio 主标签提取
  "secondary_tags": [],     // 0-3 条，辅助标签
  "story_assets": [],       // 0-N 条，从 bio + desc 抓
  "topic_focus": [],        // 5-8 个，从标题词频
  "tone_palette": [],       // 子圈层默认 +/- 调整
  "voice_signature_phrases": [],   // ≥3 条短语
  "persona_anchors_for_rewrite": {},  // 4 字段对象
  "form_capability": {},    // 4-5 个 form 的 true/false
  "form_routing": {},       // pattern → form 默认映射
  "constraints": [],        // ≥3 条红线
  "_synthesis_notes": "<一段 markdown 说明判定子圈层的依据>"
}
```

## 十、常见误判 & 兜底

- **粉丝 < 100 + 笔记 < 5**：数据太稀，warn user，建议手动补充
- **bio 完全空白**：fallback 用 IP + 笔记主题判定子圈层，标 `needs_user_review: true`
- **多子圈层信号相当**（票数差 < 5）：选 2 个 candidate，让用户裁定
- **完全脱离心理/成长大圈层**（如美食/穿搭）：直接 abort，提示这套 lens 不适用
